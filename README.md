# AL SHEIKHA STYLE — متجر العبايات الإلكتروني

ثيم **شوبيفاي** عربي أصلي (RTL) لمتجر عبايات **الشيخة ستايل** — إحدى علامات **الشيخة قروب** (الشركة الأم).

> **الحالة الآن:** نقطة البداية. لم يُعتمد تصميم ولا ألوان بعد.

## ما في المستودع

| المجلّد | الغرض |
|---|---|
| `brand/` | ملفّات الهويّة: الشعار بصيغه المختلفة، وما يُعتمد من ألوان وخطوط |
| `theme/` | ملفّات ثيم شوبيفاي (تُصدَّر ZIP ويُرفع في لوحة شوبيفاي) |
| `preview/` | معاينة الشكل قبل الرفع إلى شوبيفاي |
| `docs/` | قرارات الهويّة والتوثيق |
| `tools/` | سكربتات مساعدة |

## الشعار المطلوب

الملفّ المتاح حالياً (`logo sheikha style.pdf`) يحتوي **صورة نقطيّة 899×1600 بخلفيّة بيضاء** لا رسماً متجهيّاً. المطلوب لجودة أعلى:

- **PNG بخلفيّة شفّافة** — ضروري، وإلا ظهر مربّع أبيض حول الشعار على خلفيّة الموقع.
- **SVG أو AI/EPS** (متجهي) — مفضّل، يبقى حادّاً على كل الشاشات وفي الطباعة.
- نسخة **أفقيّة** للشعار إن وُجدت — الشعار الحالي طويل (نسبة 0.56) ويصعب وضعه في شريط علوي.

## المعاينة

`index.html` في الجذر = معاينة الهويّة والتصميم. لفتحها على الجوّال يجب تفعيل GitHub Pages مرّة واحدة:

**Settings → Pages → Source: `main` / `/ (root)` → Save**

ثم الرابط: `https://tihou74.github.io/AL-SHEIKHA-STYLE/`

## الفحص قبل النشر

```bash
python3 tools/check_page.py index.html
```

يتأكّد أن كل مرجع محلّي موجود، وأن الوسوم متوازنة، وأنّ `letter-spacing`
لا يُطبَّق على نصّ عربي (يقطع اتّصال الحروف). مُجرَّب على كسور مصطنعة ويسقط عليها.
