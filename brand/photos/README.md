# صور العبايات

## ارفع الصور **بهذه الأسماء بالضبط** وتظهر في المعاينة فوراً

| الاسم | مكانها في الموقع |
|---|---|
| `hero-1.jpg` | الصورة الكبيرة الأولى في أعلى الصفحة |
| `hero-2.jpg` | الصورة الكبيرة الثانية |
| `p1.jpg` … `p6.jpg` | ستّ عبايات في شبكة «وصل حديثاً» |
| `editorial.jpg` | صورة قسم «الخياطة على القياس» |
| `band.jpg` | شريط عريض بعرض الصفحة |
| `hero-poster.jpg` | أول لقطة من الفيديو (تظهر قبل تشغيله) |

إن رفعت أسماءً أخرى فلا مشكلة — أنا أعيد تسميتها وأربطها.

## الشروط

| | |
|---|---|
| الصيغة | **JPG** (لا HEIC — آيفون يصدّرها افتراضياً وهي لا تعمل في المتصفّحات) |
| المقاس | **أطول بُعد ٢٠٠٠ بكسل كحدّ أقصى** |
| الحجم | أقلّ من ٥٠٠ كيلوبايت لكل صورة إن أمكن |
| الاتّجاه | **طوليّة (عموديّة)** للعبايات — نسبة ٢:٣ مثاليّة |
| الاسم | حروف لاتينيّة وأرقام فقط — **لا أسماء عربيّة** (تنكسر في الروابط) |

### لماذا حدّ ٢٠٠٠ بكسل؟
سببان معاً: صورة أكبر تُبطئ الموقع على الجوّال بلا فائدة بصريّة، **ولا أستطيع أنا فتح صورة يتجاوز أحد بُعديها ٢٠٠٠ بكسل** (الجلسة تسقط). فإن رفعت أكبر، أصنع نسخة مصغّرة بالأداة `tools/safe_view.py` قبل أن أنظر إليها — لا أفتح صورة مجهولة الأبعاد أبداً.

## ما يجعل الصورة «فخمة» فعلاً

- خلفيّة **واحدة نظيفة** (جدار سادة أو ستارة) — لا غرفة فيها أثاث وأشياء.
- **إضاءة من جهة واحدة** تُظهر ملمس القماش وثنياته.
- العباية **ممتدّة بكاملها** في الصورة من الكتف إلى الأسفل.
- لقطة قريبة للتفاصيل (الطرز، الكمّ، الأزرار) تُضاعف الإحساس بالجودة.

⚠️ **صورة شخص**: إن ظهر وجه أو جسم عارضة، نحتاج **إذنها الكتابي** لاستخدام صورتها في الإعلان التجاري. ولا تستخدم صور ماركات أو حسابات أخرى إطلاقاً.
